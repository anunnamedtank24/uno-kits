# week_6_ultrasonic

[English](README.md) | 中文

全部的檔案現在都是 `.bak`，要跑哪個就留下哪個：

```bash
python src/hide.py week_6_ultrasonic/tests/1_distance     # 只留下這個（拿掉 .bak），其他改成 .bak
pio run -t upload
pio device monitor                      # 速度是 BAUD（= platformio.ini 的 monitor_speed）
```

## 接線

| 零件 | 腳 | UNO | 哪些程式 |
|---|---|---|---|
| HC-SR04 | VCC | 5V | 全部 |
| | Trig | **`TRIG_PIN`** | |
| | Echo | **`ECHO_PIN`** | |
| | GND | GND | |
| 開關模組 | OUT | **`SWITCH_PIN`** | `assignments/1_parking_sensor` |
| | VCC、GND | 5V、GND | |
| 無源蜂鳴器 | + | 100 Ω → **`BUZZER_PIN`** | `assignments/1_parking_sensor`、`assignments/2_theremin` |
| | - | GND | |
| USB | D0、D1 | 串口 | 全部 |

| 腳 | 規則 |
|---|---|
| `ECHO_PIN` | Echo 用腳位改變中斷，一組（D0 ～ D7、D8 ～ D13、A0 ～ A5）只能一個：不要跟紅外線接收器的 `IR_PIN`（week_5_NEC）同組，兩個才能一起用 |
| `TRIG_PIN` | Trig 只是輸出，任何腳都可以；最好選其他週零件沒用到的 |
| `SWITCH_PIN` | 跟 week_4_SSD1306_switch_buzzer_audio 一樣的開關接法；開關只是輪詢，不用中斷，所以可以跟 `IR_PIN` 同組 |
| `BUZZER_PIN` | D9 或 D10：無源蜂鳴器由 Timer1 直接輸出，可以調音量（PWM 的寬度），不佔 CPU |

# tests/1_distance.cpp：超音波測距

```
HC-SR04: Trig D7, Echo D8; sound at 346.5 m/s
Echo idle: LOW (ok)
 23.4 cm  echo  1351 us  |###########
100.2 cm  echo  5786 us  |##################################################>
too far / nothing (> 400 cm), or a soft / slanted surface
```

- 一個 `#` 是 `BAR_CM_PER_CHAR` cm，到 `BAR_CM`；更遠的結尾是 `>`。
- `AIR_TENTHS_C`：房間的溫度（0.1 °C），用來算音速。
- **一直 `no echo`**：沒電，或 Trig、Echo 接反（開機那行會是 `Echo idle: HIGH`）。
- **對著遠處一直 `too far`**：正常；對著布、海綿或斜的牆也會這樣。
- 拿尺比一比：誤差應該在幾 mm 內。

# tests/2_median.cpp：中位數濾波

```
HC-SR04 Trig D7, Echo D8, median of 5
raw   234 mm   median   233 mm  (5/5 good)
raw  1873 mm   median   234 mm  (5/5 good)      <- 一次錯的回音：raw 跳了，median 沒動
raw  too far   median   234 mm  (4/5 good)
```

- **raw**：這一次的量測；**median**：最近 `MEDIAN_COUNT` 次好的量測的中位數；**good**：其中幾次是好的。
- 好的不到一半時 median 印 `-`（前面沒東西，或接線有問題）。
- 手快速移動時，median 會慢約 `MEDIAN_COUNT / 2` 次才跟上：`MEDIAN_COUNT` 越大越穩、越慢。
- `ONLY_CHANGES = true`：只在 median 變了 1 cm 以上時才印。

# assignments/1_parking_sensor.cpp：按著開關的倒車雷達

按著開關、而且前面的東西比 `NEAR_MM` 近時，蜂鳴器發出 `TONE_HZ` 的聲音。音量跟距離成反比：

```
volume = MAX_VOLUME × FULL_MM ÷ 距離      （FULL_MM 以內、含 < 2 cm，都是 MAX_VOLUME，最大聲）
```

- **距離減半，音量加倍**：這就是「成反比」；在兩倍 `FULL_MM` 時是 `MAX_VOLUME` 的一半（-6 dB）。音量是 `UnoTone` 的脈衝寬度（0 ～ 255），見 [lib/buzzer](../../lib/buzzer/讀我.md#音量)。
- **放開開關、`NEAR_MM` 以外、量不到（沒回音）**：都不叫。
- **一直在量**：不管有沒有按，每 60 ms 量一次，所以一按下去馬上就有聲音；音量每 60 ms 更新一次，改音量時不會有爆音。
- 串口每 `PRINT_MS` 印一行：`pressed   23.4 cm  volume 22  (sounding)`。
- 可以改的常數在檔案開頭的設定：`NEAR_MM`、`FULL_MM`、`MAX_VOLUME`、`TONE_HZ`、`AIR_TENTHS_C`，以及每隻腳。
- **開關**：按下時 OUT 是 LOW 的模組（這裡實測的那個）`SWITCH_ACTIVE_HIGH` 用 `false`，按下是 HIGH 的用 `true`。

# assignments/2_theremin.cpp：用距離控制音高

距離在 `MIN_MM` ～ `MAX_MM` 之間時叫，**音高跟距離成線性**。音高是頻率的對數，所以每移動同樣的距離，音高變化同樣的音程（像在琴鍵上等距移動），不是同樣的 Hz：

```
t  = (距離 - MIN_MM) ÷ (MAX_MM - MIN_MM)          MIN_MM 是 0，MAX_MM 是 1
hz = HZ_AT_MIN × (HZ_AT_MAX ÷ HZ_AT_MIN)^t        log(hz) 從 log(HZ_AT_MIN) 線性走到 log(HZ_AT_MAX)
```

| 參數 | 說明 |
|---|---|
| `MIN_MM` | 最近會叫的距離；HC-SR04 量得到 20 ～ 4000 mm |
| `MAX_MM` | 最遠會叫的距離 |
| `HZ_AT_MIN` | 在 `MIN_MM` 的頻率 |
| `HZ_AT_MAX` | 在 `MAX_MM` 的頻率；比 `HZ_AT_MIN` 高就變成越遠越高 |
| `VOLUME` | 0 ～ 255 |

- **音和音隔多遠**：整段跨 log2（`HZ_AT_MIN`、`HZ_AT_MAX` 大的除以小的）個八度，所以一個八度是（`MAX_MM` − `MIN_MM`）÷ 這個數，一個半音是它的十二分之一；Hz 不是等差，但聽起來是等距。
- **範圍外或量不到**：不叫。
- 每 60 ms 量一次，換音高時不會有爆音；手要穩，HC-SR04 本身有幾 mm 的誤差（約四分之一個半音）。
- 串口每 `PRINT_MS` 印一行：`23.4 cm  775 Hz`。
- 編譯期檢查：`MIN_MM < MAX_MM`、在 20 ～ 4000 mm 內、頻率在 31 ～ 20000 Hz 內，不對就編譯錯誤。
