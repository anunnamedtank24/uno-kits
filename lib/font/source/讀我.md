# font/source

[English](README.md) | 中文

在電腦上跑的工具。需要 Python 3、`pip install pillow`。都在 `lib/font` 裡執行。

## 檔案

| 檔案 | 作用 |
|---|---|
| `convert.py` | 字型 → `output/*.h`，並把新產生的那個加進 `output/selected.h` |
| `check.py` | 檢查 `output/` 的每個檔案：目前的格式、原始檔沒變（`convert.py` 每次轉完會自動跑） |

## 用法

```bash
cd lib/font
python source/convert.py assets/menlo.ttf output --height 23
python source/convert.py assets/menlo.ttf output --height 46 --first 48 --last 57
python source/check.py
```

## convert.py

### 支援的檔案

| 副檔名 | 怎麼讀 |
|---|---|
| `.ttf`、`.otf` | Pillow（FreeType） |

### 參數

| 參數 | 預設 | 說明 |
|---|---|---|
| `--height` / `--width` / `--size` | `--height 16` | 最多選一個：格子高度、最寬字元的寬度，或 FreeType 的字型大小 |
| `--first` / `--last` | 32 / 126 | 字元碼範圍 |
| `--default` | `?` | 範圍外的字元畫成哪個字 |
| `--name` | `{字型}_{參數名}_{值}_first_{f}_last_{l}_default_{碼}`（見下面的檔名） | 檔名和 struct 名稱 |
| `--board FILE` | `platformio.ini` 的 `custom_board`（UNO：`lib/Uno/board.json`） | 主板的數字：Flash 的大小和放常數的方式（UNO：`PROGMEM`、`avr/pgmspace.h`）、時脈、畫圖的週期… 不算在 `// options:` 裡，記在 `// board:` |

- **檔名**：`{字型}_{參數名}_{值}_first_{f}_last_{l}_default_{碼}.h`，struct 同名。`assets/` 外面的檔案前面加上資料夾；撞名加 `_2`、`_3`，不蓋掉別的（見 [output/讀我.md](../output/讀我.md#名稱和來源)）。

### 流程

每個字存成一組形狀（點、橫線、直線、矩形）。形狀剛好蓋住字的像素，可以互相重疊，但不畫到字外面。用畫圖時間找最便宜的組合：

1. 找出所有最大矩形（上下左右都不能再長）。
2. 用分支定界找成本最低的組合。
3. 把重疊的部分盡量縮掉。
4. 依大小分成點、橫線、直線、矩形。

**畫圖時間**（主板的 `board.json`，UNO 的估計）：每個形狀約 480 週期、每個像素約 44 週期、每個儲存 byte 約 6 週期。跟一個一個點畫比，小字只要約 30% 的時間、大字約 21%。

### 錯誤和警告

| 情況 | 處理 |
|---|---|
| 字型檔不存在、副檔名不支援 | 錯誤，不產生檔案 |
| 範圍或大小超過格式上限（見 [讀我.md](../讀我.md#輸入限制)） | 錯誤，不產生檔案 |
| 預設字元不在字型裡 | 錯誤 |

## check.py

| 類型 | 項目 |
|---|---|
| 錯誤 | `selected.h` 不存在或沒有 include guard |
| 錯誤 | include 的檔案不存在、不在 `output/` 裡、include 自己、重複 include |
| 錯誤 | 檔案是舊版 `convert.py` 產生的（沒有 `// format:`，或不是目前的 `FORMAT_VERSION`） |
| 錯誤 | 檔案裡沒有 `struct font::{檔名}`（例如被改過名字） |
| 錯誤 | 原始字型跟產生時不一樣（比對 sha256） |
| 錯誤 | 檔案的 `// board:` 不是 `platformio.ini` 的 `custom_board` 那塊主板（或它的數字改過）：`python src/clean.py --rebuild` |
| 警告 | 原始字型找不到（沒辦法確認有沒有變） |
| 警告 | `output/` 裡有沒被選的 .h |

檢查不通過時結束碼是 1。
