# font/output

English | [中文](讀我.md)

The fonts made by `source/convert.py` and by macros in programs, `namespace font`. Never edit the files here by hand: to change one, convert it again.

## Files

```
output/
├── selected.h    written automatically: lists every .h here, font.h includes it
├── registry.h    written automatically: the types of FONT("path", "options") in the current program
└── *.h           the converted fonts: made by convert.py by hand or by FONT(...), all here, in the same format
```

## selected.h, registry.h

- Both are written by `src/tools/assets.py` before every build (`convert.py` also adds a new one to `selected.h`); nothing to edit by hand.
- `selected.h` lists **every** one: the unused ones take no Flash (the data is in arrays inside `inline` functions, with the board's flash attribute (`board.json`; UNO: `PROGMEM`); never called, never generated; measured: the same Flash).
- `registry.h` has only the `FONT(...)` of the current program.
- `python source/check.py` checks that every file has the current format and an unchanged source; `convert.py` checks once after every conversion.

## The generated struct

```cpp
namespace font {
    struct menlo_height_23_first_32_last_126_default_63 {
        static constexpr uint8_t gridHeight;     // the height of each character
        static constexpr uint8_t first, last;    // the range of character codes
        static constexpr uint8_t defaultChar;    // drawn for characters outside the range
        static constexpr uint8_t defaultIndex;   // its place in widths / offsets
        static inline const uint8_t *getWidths();    // the width of each character
        static inline const uint16_t *getOffsets();  // where each character starts in getShapes()
        static inline const uint8_t *getShapes();    // the shapes of all characters, format below
    };
}
```

**The start of a file**:

```
// generated by convert.py, do not edit
// options: --height 23                                         ← the arguments when made (src/tools/assets.py finds converted ones by it)
// format: 2                                                    ← the format version
// board: Arduino UNO (ATmega328P, 16 MHz) sha256 …            ← the board it was converted for (custom_board; when the numbers differ, check.py errors and it is converted again before compiling)
// source: assets/menlo.ttf sha256 …                            ← the source file and its hash
```

When the format changes, raise `FORMAT_VERSION` in `check.py` so that old files are caught.

## Format (format 2: shapes)

- **Each character**: first 4 counts (points, horizontal lines, vertical lines, rectangles), then in order:
  - points: `(x, y)`
  - horizontal lines: `(x, y, w)`
  - vertical lines: `(x, y, h)`
  - rectangles: `(x, y, w, h)`
- **Coordinates**: relative to the character's top left corner, in px.
- **Drawing**: `graphics::Text` calls `drawPoint`, `drawHLineSize`, `drawVLineSize`, `drawFilledRectSize` in order.

## Names and sources

The start of every .h says which file and which options it was converted from:

```
// options: --fit 120x80 --palette 16
// source: assets/sunset.jpg sha256 1413…
```

`FONT("path", "options")` in a program finds a converted file by these two lines: the same file with the same options (the order and the form `--fit=…` do not matter) is used as it is, only otherwise is it converted. So converted by hand or by a macro, each is converted only once.

| Rule | Explanation |
|---|---|
| Names | the rule of `convert.py`: `{file name}_{settings}`, the struct named the same (`font::name`) |
| Files outside `assets/` | the folders go in front of the file name (relative to the project; outside the project, to the home folder), e.g. `~/Music/Game/title.mp3` → `music_game_title_…`, so files with the same name in different folders never mix |
| Characters that are not letters or digits (e.g. Japanese) | left out, with a 6-digit hash added instead, e.g. `16 戦い：ウォロ.aiff` → `…_16_7b5dc7_…` |
| Equal names (the name does not hold every option, or another source) | `_2`, `_3`… added, never replacing another file |
| The source changed | a warning when compiling; `python src/tools/assets.py --force` converts it again (replacing the one with the same name) |
| The source moved or deleted | it still compiles as long as the output is there (the old path in the program still finds it) |
| Unwanted ones | `python src/tools/assets.py --unused` lists those no program (`.bak` included) uses; delete them yourself |
